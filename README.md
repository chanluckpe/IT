# 내 통역 비서

한국어로 말하면 영어·일본어·베트남어·태국어로 실시간 통역해서 음성으로 들려주는 모바일 웹앱입니다.
상대방 언어는 **설정 → 상대방 언어**에서 고릅니다 (기본: 영어).
**영어 듣기** 버튼을 누르면 상대방의 영어를 한국어로 통역해 줍니다.

## 사용법

### 자동 대화 모드 (기본)
1. **대화 시작**을 누르고 한국어로 말합니다.
2. 말을 멈추면(기본 1.0초, 설정에서 조절) 영어 음성이 나오고, 마이크가 자동으로 영어 듣기로 바뀝니다.
3. 상대방이 영어로 말을 마치면 한국어 음성으로 들려주고 다시 내 차례로 돌아옵니다.
4. 차례가 어긋나면 오른쪽 **차례 바꾸기**를 누릅니다. 대화 중 아래 카드가 빨간색이면 내 차례, 초록색이면 상대방 차례입니다.

대화 방식(자동 대화 / 직접 선택)과 통역 언어는 오른쪽 위 **설정**에서 바꿉니다.

### 직접 선택 모드
1. 파란 **마이크 버튼**을 누르고 한국어로 말합니다. 문장이 끝날 때마다 영어 음성이 나옵니다.
2. 상대방이 영어로 말할 차례면 오른쪽 **영어 듣기**를 누릅니다.

### 통역 목소리
- **내 말**(한국어 → 상대방 언어)은 항상 남자 목소리로 들려줍니다.
- **상대방 말**(→ 한국어)은 **설정 → 통역 목소리**에서 여자/남자를 고릅니다.
- 각 항목에서 휴대폰에 설치된 목소리를 직접 고르고 **미리 듣기**로 확인할 수 있습니다. 기본은 자동 선택(장난감·로봇 음성 제외)입니다.
- 휴대폰에 해당 언어 음성이 없으면 온라인 음성(여자)으로 나옵니다.

### 사진 번역 (카메라)
오른쪽 위 **카메라** 아이콘을 누르면 카메라가 켜집니다. 메뉴판·안내문·문서를 찍으면 글자를 인식해서
사진 위 원래 글자 자리에 한국어를 덮어 보여주고, 아래에 원문 → 한국어 목록도 보여줍니다.
- 설정의 **상대방 언어**(영어·일본어·베트남어·태국어) 글자와 영어를 함께 읽습니다.
- **원문 보기**로 원래 사진과 비교, **확대**로 크게 볼 수 있고, **앨범**에서 저장된 사진을 고를 수도 있습니다.
- 어두운 곳에서는 위쪽 **플래시** 버튼을 쓸 수 있습니다(지원하는 휴대폰만).
- 처음 한 번은 글자 인식 데이터(언어별 1~3MB)를 내려받고, 이후에는 휴대폰에 저장된 것을 씁니다.

### 대화 맥락 반영
앞에서 나눈 대화 최근 3개(5분 이내)를 새 문장과 함께 번역기에 보내, 생략된 주어나 "기차로요" 같은 짧은 대답이 대화 흐름에 맞게 번역되도록 합니다. 설정에서 끌 수 있고, 휴지통 버튼으로 대화를 지우면 맥락도 초기화됩니다.

말풍선의 **크게 보기**로 영어 문장을 화면 가득 띄워 상대에게 보여줄 수 있습니다.

## 휴대폰에 앱처럼 설치하기

- **안드로이드 (Chrome)**: 주소 접속 → 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**
- **아이폰 (Safari)**: 주소 접속 → 공유 버튼 → **홈 화면에 추가**

처음 마이크 버튼을 누르면 마이크 권한을 묻습니다. **허용**을 눌러 주세요.

## GitHub Pages 배포

저장소 **Settings → Pages** 에서 Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)` 로 설정합니다.
이후 `main`에 올라가는 변경은 1~2분 안에 자동으로 반영됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면, 음성 인식, 번역, 음성 출력) |
| `manifest.webmanifest` | 홈 화면 설치용 앱 정보 |
| `icon.svg`, `icon-192.png`, `icon-512.png` | 앱 아이콘 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서빙하도록 설정 |

## 지원 브라우저

- 안드로이드: Chrome
- 아이폰: Safari (iOS 14.5 이상)
